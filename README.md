# Real World RTS — Android 1.0

Kompletna grywalna wersja prototypowa:
- współczesny RTS
- baza gracza i baza przeciwnika
- zasoby i paliwo
- produkcja czołgów, piechoty i rozpoznania
- ruch jednostek
- walka i punkty życia
- proste AI przeciwnika
- trzy punkty strategiczne
- warunek zwycięstwa/porażki
- pauza, restart i timer
- interfejs dotykowy
- projekt przygotowany do automatycznego budowania APK przez GitHub Actions

## APK bez Android Studio
Wgraj zawartość projektu do repozytorium GitHub, następnie:
Actions -> Build Real World RTS APK -> Run workflow.
Po zakończeniu pobierz artefakt RealWorldRTS-debug-apk.

## Ważne
To jest kompletna, mała grywalna wersja 1.0, ale nie jest jeszcze pełną wysokobudżetową grą 3D. Kolejne etapy mogą dodać prawdziwą geograficzną mapę Szczecina, teren 3D, drogi z danych OSM, bardziej zaawansowane AI, artylerię, lotnictwo, logistykę, kampanię i multiplayer.
